The task

Faster than the reference, correct on 14 shapes

Track 3 asks for a GPU implementation of a fixed Transformer block that runs faster than the organizer's reference implementation, while matching it within a per-element tolerance across 14 published input shapes.

relative error < 0.02  ·  absolute error < 0.002
Hardware

RunPod, A100-SXM4-80GB

Our university cluster's shared A100 queue became the actual bottleneck mid-project — multi-hour waits between runs. We moved to on-demand RunPod A100 instances, provisioned per benchmark and torn down immediately after.

Method

A self-improving loop, six phases, two agents

The two agents share no state except these two files — TODO.md carries ranked hypotheses one way, journal.jsonl carries every measured result back. Every claim reaching the research agent already passed the correctness gate; speed is never discussed before that. The next iteration's plan reads the same log.
